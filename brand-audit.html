Identified Gaps — Prioritized Fix List
01

Brand Font Not Implemented

The guidelines specify Texta (LLTor Tiglo). The app currently uses Inter. Replace with a licensed Texta font or use Plus Jakarta Sans / DM Sans as an approved substitute. Update layout.tsx font import and --font-sans CSS variable.

High
02

Dark Mode Is Default — Brand Is Light-First

The app defaults to dark theme (defaultTheme="dark" in ThemeProvider). The brand guidelines show all templates in light mode. Change default to "light" in theme-provider.tsx so the app matches brand intent out of the box.

High
03

Dashboard Missing Charts (Idea Status line chart)

Template 2 prominently shows a multi-line chart for "Idea Status" over time. The dashboard page has stat cards but no chart. Wire up the chart component (likely Recharts or Chart.js already in the codebase) to the /api/dashboard endpoint.

High
04

Auth Landing — Missing Lightbulb Illustration + Icon Trio

Template 1 shows a stylized lightbulb + upward chart graphic on the red panel, plus 3 feature icons (Capture / Track / Build). Current implementation has text bullets only. Add SVG illustration and icon row to (auth)/layout.tsx.

Medium
05

Hero Copy Doesn't Match Brand Tagline

Brand: "Got an idea? Log it. Track it. Build it." — App: "Capture Every Opportunity. Drive Real Value." Consider aligning to brand copy or getting sign-off on the custom variant.

Medium
06

Dashboard Missing "Ideas in Progress" Progress-Bar List

Template 2 shows a category breakdown (Services 81%, Testing, Seeking Approval) with horizontal progress bars. This is absent from the current dashboard. Add a widget using /api/dashboard data grouped by category/status.

Medium
07

Campaign Banner Component (Template 3) — Not Built

A reusable red promotional banner ("Got an Idea? Log It Now") is defined in the brand kit. Build a CampaignBanner component using bg-[#B12B35] with logo, headline, and white CTA button. Could appear at top of dashboard.

Medium
08

Accent Blue / Navy Not Used in Status Badges

#2E75B6 and #003466 appear only in dashboard icon colors. Brand guidelines intend them for info states, secondary accents, and chart lines. Extend their use to status chips, info alerts, and chart series colors.

Low
09

Geist Mono Referenced But Not Loaded

--font-geist-mono is in the @theme CSS block but Geist Mono is never imported in layout.tsx. Either import it or remove the reference to avoid silent fallback to system monospace.

Low
10

Template 4 (Portal Switcher) — Architectural Decision Needed

Brand shows a multi-portal card grid (Exemplics hub). Value Portal is currently standalone. Decide whether to build a portal-switcher landing page or confirm this is out of scope for this deployment.

Low
